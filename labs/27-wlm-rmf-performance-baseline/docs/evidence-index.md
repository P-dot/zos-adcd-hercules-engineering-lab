# Evidence Index

The directory contains all screenshots supplied in the final evidence document, preserved in document order as `01-evidence.png` through `74-evidence.png`.

Key evidence groups:

- Early images: WLM runtime display, WLM ISPF definition, service policy, workloads, service classes and subsystem classification.
- Middle images: RMF Monitor III failure and GDDM/LNKLST/PARMLIB troubleshooting evidence.
- Later images: RMF Monitor II menus and reports (`SPAG`, `SRCS`, `SENQ`, `ARD`, `ASRM`).
- Final images: SMF archive discovery, RMF Postprocessor setup/input/options, successful submit, and spool failure showing `SORTIN - DATA SET NOT FOUND`.

The complete set is retained rather than selectively discarding troubleshooting evidence so the lab remains auditable from initial observation through final conclusion.
