# Commands — LAB18B

## Baseline checks

```text
/D SMF
/D R,L
/D IPLINFO
/D PARMLIB
```

## Browse original SMF parameters

```text
ADCD.Z111S.PARMLIB(SMFPRM00)
F DSNAME
F RECORDING
F STATUS
```

## Define new MAN data sets

Member: `IBMUSER.HARDEN.CNTL(DEFMANB)`

```jcl
//DEFMANB  JOB (ACCT),'DEFINE SMF MAN',CLASS=A,MSGCLASS=X
//STEP01   EXEC PGM=IDCAMS
//SYSPRINT DD SYSOUT=*
//SYSIN    DD *
 DELETE SYS1.MAN4 CLUSTER PURGE
 DELETE SYS1.MAN5 CLUSTER PURGE
 DELETE SYS1.MAN6 CLUSTER PURGE
 SET MAXCC = 0

 DEFINE CLUSTER (NAME(SYS1.MAN4) -
        VOLUME(ZVOL00) -
        NONINDEXED -
        CYLINDERS(80 0) -
        REUSE -
        RECORDSIZE(4086 32767) -
        SPANNED -
        SPEED -
        CONTROLINTERVALSIZE(4096) -
        SHAREOPTIONS(2 3)) -
        DATA (NAME(SYS1.MAN4.DATA))

 DEFINE CLUSTER (NAME(SYS1.MAN5) -
        VOLUME(ZVOL00) -
        NONINDEXED -
        CYLINDERS(80 0) -
        REUSE -
        RECORDSIZE(4086 32767) -
        SPANNED -
        SPEED -

 DEFINE CLUSTER (NAME(SYS1.MAN6) -
```

## Alternate SMF parameter member

Member: `USER.PARMLIB(SMFPRMB8)`

Only the `DSNAME` list was extended:

```text
DSNAME(SYS1.MAN1,
       SYS1.MAN2,
       SYS1.MAN3,
       SYS1.MAN4,
       SYS1.MAN5,
       SYS1.MAN6)
```

## Activate and verify

```text
/SET SMF=B8
/D SMF
/D R,L
```
