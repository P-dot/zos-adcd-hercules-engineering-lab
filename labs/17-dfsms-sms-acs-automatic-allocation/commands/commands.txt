## Hercules persistence check

Confirm these lines exist in `F:\ZOS111\hercules.cnf` before relying on the volumes after IPL:

```text
0A9E 3390 F:\ZOS111\SMS000.CCKD
0A9F 3390 F:\ZOS111\SMS001.CCKD
0AA0 3390 F:\ZOS111\SMS002.CCKD
```

PowerShell helper:

```powershell
$cfg = 'F:\ZOS111\hercules.cnf'
$bak = 'F:\ZOS111\hercules.cnf.BEFORE_SMSPOOL'
Copy-Item $cfg $bak -Force
$lines = @(
'0A9E 3390 F:\ZOS111\SMS000.CCKD',
'0A9F 3390 F:\ZOS111\SMS001.CCKD',
'0AA0 3390 F:\ZOS111\SMS002.CCKD'
)
$c = Get-Content $cfg
foreach ($line in $lines) {
  $addr = $line.Split()[0]
  if ($c -match "^\s*$addr\s+") {
    $c = $c -replace "^\s*$addr\s+.*$", $line
  } else {
    $c += $line
  }
}
Set-Content -Path $cfg -Value $c -Encoding ASCII
Select-String -Path $cfg -Pattern '^\s*0A9E\s+|^\s*0A9F\s+|^\s*0AA0\s+'
```

## ACS source routines

`IBMUSER.HARDEN.CNTL(ACSSTOR)`:

```text
PROC STORCLAS
IF &DSN(1) = 'IBMUSER' AND &DSN(2) = 'SMSLAB' THEN
  SET &STORCLAS = 'SMSLAB'
ELSE
  SET &STORCLAS = ''
END
```

`IBMUSER.HARDEN.CNTL(ACSGRP)`:

```text
PROC STORGRP
IF &STORCLAS = 'SMSLAB' THEN
  SET &STORGRP = 'SMSPOOL'
ELSE
  SET &STORGRP = 'DBCLASS'
END
```
