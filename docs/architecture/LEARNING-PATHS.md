# z/OS Learning Paths

The ecosystem supports multiple professional and educational routes.

## Path 1 — New z/OS Team Member

```text
MVS_TSO_ISPF
→ TSO/E
→ ISPF
→ data sets / members
→ SDSF
→ JCL_LABS
→ basic JES2 execution
```

## Path 2 — MVS / TSO / ISPF Power User

```text
MVS_TSO_ISPF
→ advanced ISPF
→ REXX
→ ISPF services
→ operational automation
```

## Path 3 — Batch Operator / Production Control

```text
MVS_TSO_ISPF
→ SDSF
→ JCL_LABS
→ JES2
→ scheduler
→ dependencies / resources
→ failure diagnosis
→ restart / rerun
```

## Path 4 — Mainframe Application Developer

```text
JCL
→ COBOL
→ VSAM
→ Db2
→ CICS
```

Complementary languages:

- PL/I
- REXX
- Assembler

## Path 5 — z/OS Security

```text
TSO/ISPF

→ data set protection
→ OPERCMDS
→ USS security
→ JES / scheduler controls
→ Communications Server security
→ SMF evidence
```
