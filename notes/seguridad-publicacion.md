# Seguridad de publicación

No subir al repositorio público:

- Archivos `.CCKD`
- Backups de discos
- Contraseñas
- Dumps completos
- Licencias
- Binarios propietarios
- Material redistribuible de z/OS
- Capturas con contraseñas o datos sensibles

Sí subir:

- Capturas de laboratorio
- Markdown explicativo
- Evidencias textuales sanitizadas
- Mapas propios
- Comandos usados
- Conclusiones técnicas
